## 🎵 完整功能一览

### 1. 歌单导入与在线音源

- 支持 QQ 音乐、汽水音乐、酷我等多平台歌单一键导入，自动解析曲目清单
- 导入后支持一键全网换源抓取音频，多线路轮询提升下载成功率
- 内置在线曲库搜索，支持试听、批量加入歌单、一键下载至本地曲库
- 外部歌曲导入后后台静默补全高清专辑封面与 LRC 歌词，支持批量匹配
- 在线未加载曲目播放保护，加载过程中播放键置灰并显示加载动画，防止误点窜台

### 2. 本地曲库与文件管理

- 支持 MP3 / FLAC / M4A / WAV / OGG / LRC 等主流音频与歌词格式
- 自动读取 ID3v2 / Vorbis / MP4 Atom 标签，解析内嵌封面与歌词
- 支持本地文件夹零拷贝索引，自动创建同名文件夹歌单
- IndexedDB 持久化离线存储，曲库、封面、歌词本地保存，打开即播
- 存储空间可视化管理，一键清理缓存，支持配置文件导入导出备份
- 默认按添加时间降序排列，支持长按滑动批量多选

### 3. LIAO 音效 v2 声学舱

- 12 大声场预设：重低音、3D 环绕、8D 旋转、音乐厅、人声增强、Hi-Fi 晶莹解析、黑胶胆机、Livehouse 现场、二次元电音、全景影院、深夜耳语、母带监听
- 五段实时参量均衡，附带流行、摇滚、古典、电子等多曲风预设
- 立体声声场宽度调节、混响量控制、极低频下潜与高频泛音激励
- 432Hz 自然治愈调律一键切换
- KTV 人声伴奏分离模式，支持原声、伴奏、纯人声切换
- 耳机耳道听感补偿，适配入耳式、头戴式、音箱等不同设备
- 环境白噪音混音：微雨、黑胶底噪、篝火、海浪等背景声景
- 智能响度归一化，切歌音量平稳不突兀

### 4. 播放与交互体验

- 双轨交叉无缝切歌，基于正余弦等功率曲线实现淡入淡出
- 弹簧物理歌词渲染，逐行错峰跟随，点击任意歌词零延迟跳转进度
- 双语歌词同屏渲染，原文与译文合并显示不跳行
- 单句复读功能，双击歌词即可循环播放指定句子
- 播放倍速调节，变速不变调
- 睡眠定时、屏幕常亮、触控震动反馈、UI 交互微音效
- 全界面手势操作：封面右滑展开、面板左滑收起、左右轻扫切换页面
- 桌面端键盘快捷键支持，快捷控制播放、音量与模式切换
- 老爷机精简模式，降低特效负载，保障老旧设备流畅运行

### 5. 沉浸式视觉与歌单墙

- 4 种沉浸式歌词风格，可自由切换：
  - **沉浸式巨幕**：柔焦水波纹 + 中心大字，封面动态取色铺满氛围
  - **瞬影分镜**：非线性甩镜 + 词块接力，支持丝滑流云、电影推镜等多种切入动效
  - **歌词看板**：随机错落矩阵 + 非线性镜头跟随，支持透明度、模糊度、色调自定义
  - **原生双栏**：左侧专辑封面 + 右侧滚动歌词，经典简洁布局
- 沉浸式无限歌单墙：封面无缝平铺全屏，支持拖拽漫游、滚轮 / 双指缩放、键盘 WASD 操控
- 正在播放曲目动态音律标识，鼠标悬浮任意尺寸封面均丝滑展开为 2×2 大磁贴并轻微上浮
- 封面形态自定义：现代圆角、黑胶唱片、复古磁带、极简画框
- 实时频谱可视化：丝滑波浪、镜像霓虹多种样式可选
- 动态流光背景，多种光效风格与速度调节

### 6. MV 与海报工坊

- 沉浸式 MV 制作工坊，支持巨幕、分镜、看板三种风格导出有声 MP4
- 硬件加速视频编码，后台静默录制，不影响前台操作
- 歌词金句海报生成，一键导出可直接分享
- 支持多档渲染清晰度调节，适配不同设备性能

### 7. 个性化设置

- 深浅主题切换，支持跟随系统自动切换
- 中英双语界面完整适配

## ⚙️ 技术架构

整个应用为单 HTML 文件架构，基于原生前端技术实现，无需后端服务，可直接部署或打包为多端客户端。

- **声学引擎**：Web Audio API 搭建 32-bit 浮点 DSP 管线，实时 FFT 频谱分析驱动视觉动效
- **渲染优化**：GPU 硬件加速径向光斑，封面预模糊处理，零频闪渲染，移动端持久流畅
- **本地存储**：IndexedDB 持久化离线曲库，支持大容量音频、封面、歌词存储
- **标签解析**：原生支持 ID3v2、Vorbis、MP4 Atom 多种音频标签读取
- **热更新机制**：内置 OTA 多源版本比对，高版本优先，自动静默升级
- **跨端适配**：响应式布局自动适配桌面宽屏与移动窄屏，兼容 Chromium 内核与 WebView2
